Solaris Wing: Caldera Sortie is an original 3D WebGL flight game featuring 6-DOF quaternion aerodynamics, a lit 3D cockpit with live MFD instruments, PAPI-guided Runway 09 landings, and multi-mission volcanic archipelago sorties. Built from scratch in vanilla ES modules with vendored Three.js and zero external network requests.

## Run it

```sh
node serve.ts
```
